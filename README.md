## Quick Start: Launch WebLab Dashboard

The complete dashboard application is located in the [`miniproject/`](miniproject/) folder.

### Running with Node.js
```bash
cd miniproject
node scripts/server.js
```
*Or via npm:*
```bash
cd miniproject
npm start
```
Open **`http://localhost:3000/miniproject/index.html`** in your browser.
